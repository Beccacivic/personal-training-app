# Personal Training App

A cross-platform personal training app for iOS and Android, built with Expo and React Native.

## Getting started

```bash
npm install
npx expo start
```

Then scan the QR code with Expo Go, or press `i` for the iOS simulator / `a` for the Android emulator.

## Included in this scaffold

- Dashboard with weekly activity and next workout
- Workout plan and exercise library
- Guided workout session with a rest timer
- Progress metrics and recent personal records
- Bottom tab navigation
- TypeScript and Expo configuration

This first version uses local sample data. Authentication, persistence, backend sync, and push notifications can be added next.
